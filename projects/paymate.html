Overview

PayMate is a personal finance management application designed to make everyday expense tracking simpler and more transparent. It uses OCR technology to extract information from receipts, automatically categorizes expenses, tracks budgets, analyzes spending trends, and helps users manage shared expenses. The project focused on translating financial management needs into a structured software solution. Through comprehensive requirements analysis and system design, the team defined PayMate's functionality, system architecture, data structure, user flows, and external service integrations before transforming them into a high-fidelity mobile application prototype.

Problem & Objectives

Managing everyday expenses shouldn't feel complicated.

Tracking personal expenses often involves manually recording transactions, organizing receipts, monitoring budgets, and calculating shared costs across multiple tools.

PayMate brings these activities into one connected experience.
